Sistema Integral de Gestión Escolar (SIGE)

Descripción del proyecto

El Sistema Integral de Gestión Escolar (SIGE) es una plataforma digital que tiene como finalidad facilitar la administración y organización de la información de una institución educativa.

Objetivo general

Desarrollar un sistema que permita gestionar de manera organizada la información académica y administrativa de alumnos, docentes y materias.

Funciones principales

- Inicio de sesión.
- Registro de alumnos.
- Registro de docentes.
- Administración de materias.
- Consulta de calificaciones.
- Control de asistencias.
- Administración de horarios.
- Generación de reportes.
